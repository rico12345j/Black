# 🐙 GitHub Clone

## 📖 نظرة عامة

**GitHub Clone** هو نسخة مقلدة من منصة GitHub الشهيرة، تم بناؤها باستخدام **Node.js** و **Express** و **MongoDB**. توفر المنصة جميع الميزات الأساسية التي تجعل GitHub منصة التطوير الأولى في العالم.

## 🚀 الميزات الرئيسية

### 👤 المستخدمون
- ✅ إنشاء حساب وتفعيل البريد الإلكتروني
- ✅ تسجيل الدخول (Local, GitHub OAuth, Google OAuth)
- ✅ إعادة تعيين كلمة المرور
- ✅ ملف شخصي مع سيرة ذاتية وصورة
- ✅ متابعة وإلغاء متابعة المستخدمين

- ✅ سجل التغييرات (Commits)
- ✅ الفروع (Branches)

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **Node.js** | الخادم الخلفي |
| **Express.js** | إطار العمل |
| **MongoDB** | قاعدة البيانات |
| **Mongoose** | ODM |
| **Passport.js** | المصادقة |
| **JWT** | التحقق من الهوية |
| **Socket.IO** | الاتصال الفوري |
| **bcrypt** | تشفير كلمات المرور |
| **Nodemailer** | البريد الإلكتروني |
| **Multer** | رفع الملفات |
| **Sharp** | معالجة الصور |

## 📦 التثبيت

### المتطلبات
- Node.js 16+
- MongoDB 5+
- npm 8+

### الخطوات
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-username/github-clone.git
cd github-clone

# 2. تثبيت الاعتماديات
npm install

# 3. إعداد ملف البيئة
cp .env.example .env
# عدل الملف بإضافة المفاتيح المطلوبة

# 4. تشغيل قاعدة البيانات
mongod --dbpath ./data

# 5. تشغيل الخادم
npm start

# 6. فتح المتصفح
http://localhost:5000
